# Dirfyn

1. Si `~/Dirfyn` n'est pas un dossier du projet sous ce nom exact (`test -d ~/mnt/Dirfyn` dans le shell), arrête-toi. Dis à l'utilisateur d'attacher au projet, depuis le sélecteur de dossiers de Cowork, le dossier `Dirfyn` de son dossier de départ ; s'il n'existe pas, de le créer là avec « Nouveau dossier », nommé exactement `Dirfyn`, D majuscule ; puis d'ouvrir une nouvelle session du projet.
2. Si `~/Dirfyn/outil/VERSION` manque, ou si l'utilisateur colle le message d'installation de Denis (il commence par « Installation de Dirfyn, poste »), lis avec ton outil de lecture `installation.md`, joint à ce skill à côté de ce `SKILL.md`, suis-le et arrête-toi.
3. Lis `~/Dirfyn/outil/SKILLS.md` (dans le shell : `~/mnt/Dirfyn/outil/SKILLS.md`) et applique ses règles communes.
4. Lis `0 - Dirfyn/fiche-client.md` du dossier client ouvert, jamais un `CLAUDE.md` à sa place. Si elle manque, dis-le, sauf pour créer un nouveau client (`nouveau-client`) ou au premier passage d'`indexer` sur un dossier existant qui n'a pas encore `0 - Dirfyn/` : là, c'est normal.
5. Choisis dans l'index de `SKILLS.md` le skill qui convient, lis son `SKILL.md` et applique-le. Si aucun ne convient, dis-le.
6. Au plus une fois par jour, cherche une version plus récente de l'outil comme `SKILLS.md` le décrit, et signale-la sans l'installer.
