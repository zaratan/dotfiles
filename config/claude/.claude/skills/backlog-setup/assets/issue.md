# Gabarit de corps d'issue

Titre : le défaut en une phrase, pas la solution. Exemples : « PROTECTION vide
imprime NON », « Index photo à plat et collisions par nom de fichier (bloquant pour
les Antilles) », « README : chemin du lien inexact ».

```markdown
**Constat (vérifié).** <Ce qui se passe, avec le pointeur `fichier:ligne`, et comment
ça a été mesuré : commande, chiffres, cas nominatifs. Sans « (vérifié) » si c'est une
lecture de code non confirmée — le dire alors explicitement.>

**Pourquoi c'est grave.** <Ce que ça produit chez le destinataire : un livrable faux,
une panne silencieuse à venir, un contrôle illisible. Une phrase suffit.>

**Piste.** <Par où commencer, ce qu'il ne faut pas faire, ce qui reste à trancher
et par qui. Une décision externe se nomme : « à demander à <personne> ».>

**Liens.** <Issues liées, le cas échéant.>

---
**Complexité (planning poker) : <N>**
```

Pour un méta-dépôt, ajouter en tête : `**Dépôt.** <nom du sous-dépôt>` et le
préfixe `[<nom>]` dans le titre.
